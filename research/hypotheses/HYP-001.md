# HYP-001 — Compact PPO provides consistent rapid surrogate learning

Status: TESTING. Registered before the governed run; short pilot results informed
configuration selection and are separately counted as development compute.

Proposition: original compact stacked PPO reaches a held-out median distance at
least five times the random baseline within five actual training minutes, on
surrogate-0.1.0. This hypothesis concerns an uncalibrated simulator only.

Independent variables: algorithm, training seed, training duration. Dependent
variables: held-out distance distribution, environment transitions, elapsed time,
resource use, policy/optimizer time. Controls: same default vehicle/train-terrain
distribution, episode horizon, held-out seeds10000–10019, action mapping and reward.

Success: five-minute ratio ≥5, then assess stability over later checkpoints.
Falsification: ratio <5. Missing checkpoint or broken provenance → INCONCLUSIVE.
Single-run uncertainty cannot establish general superiority across training seeds.

Experiment: runtime-screen pilots across seeds0,1,2; separate fresh seed42, cold-start
3600s run using experiments/definitions/one-hour-surrogate.json; no parent weights.
Final tests20000–20019 are separate from model selection. Real-game transfer is a
separate unanswered question, never an implied consequence of this hypothesis.

Eventual result: pending governed checkpoint evaluations.

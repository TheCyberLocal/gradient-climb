# Local scientific artifacts

Generated run records, Parquet telemetry, checkpoints and frames live here and are ignored
by Git. Each finalized run has a content-addressed manifest. Copy the entire run directory
when archiving or transferring evidence. Published findings retain compact run IDs and
summaries in research/; proprietary game imagery is never redistributed by this repository.

Cycle 1 is paused. The complete local run store is inventoried in
`research/experiments/cycle-1-integrity.json`; auxiliary references, diagnostic
scripts and unadopted drafts are listed in
`research/experiments/cycle-1-local-evidence.json`. No external backup is claimed.
Do not discard failure records or normalize sealed file bytes. Read
`docs/operations/resume-state.md` before resuming any work.

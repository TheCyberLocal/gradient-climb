candidate freeze or capture. No historical definition, implementation or sealed
record has been changed.

The graph contains 100 unique source hashes and 8,313,753 bytes at the selected
paths. Schema, closure and every referenced file hash were checked without
executing a reader or UI recognizer. Full source-run payload seal verification
remains an execution preflight requirement. Paths are forward-slash references
to existing bytes; legacy manifest bytes remain unchanged.

All legacy graph nodes carry `legacy-reader-ui-exposure-audit-pool-001`. This is
an exclusion grouping, not an asserted original session or an independent unit.
The source inventory names the known acquisition runs and records absent original
session IDs explicitly. The one new construction source uses its run ID as an
explicit audit grouping; it does not acquire a retrospective original session ID.

The current 58-glyph bank, its numeric manifest, both historical anchors, all
effective raw glyph sources, predecessor result manifests and all 22 UI reference
images are included. The sibling gameplay HUD and the explicitly replaced
bootstrap bank remain documented audit context; their unused manifests are not
introduced as inherited dependencies of this result-reader graph.

The mutable historical construction-label path has a different raw hash but the
same parsed JSON as the original. The inventory and draft ancestry use the
existing sealed private copy with the recorded `ed02e0f…` hash. No historical file
is repaired or rewritten.

Before the builder can run, registration must establish the protocol bytes and
registration time, the truthful exposure representation, a construction-only
declaration receipt, and a separately sealed new annotation. The executable
construction plan must embed the pinned graph object and bind exact registered
annotation artifacts. The freeze plan must use the successful new builder's
returned manifest hash and canonical run ID. Those values cannot be supplied in
advance without inventing evidence.

Finalize and commit the supplement, then bind its exact hash in the registered
protocol's `qualification_note`. The supplement's draft-protocol reference is
preparation context, avoiding a circular protocol/supplement hash. The generic
protocol's 200-label bound covers future qualification; the supplement limits this
construction to one full source region, one fitting call and one selfcheck. Any
fault or nonmatching selfcheck ends that attempt with retained costs. It authorizes
no adaptive retries or alternate images.

The prospective exposure contract now supports
`prediction_exposure_status="known"` with
`first_prediction_exposure_at=null`. The draft uses this representation because
the source is known to have been exposed and the precise first-view timestamp is
not recorded. The actual reviewer and reviewed-through cutoff still need to be
established before finalizing and hashing the audit. A capture timestamp or file
timestamp is never substituted as a view time, and the null does not claim absence.
After protocol registration and the construction declaration, complete the label
review before finalizing the audit cutoff, then publish the annotation. The cutoff
covers source seals and completed label times; it cannot preclaim a later review.
Future heldout evaluation may require a later truthful audit covering the frozen
cutoff after annotation sealing; retain both audit identities when they differ.
The supporting core/session file hashes are pinned in the preparation's readiness
record; a committed source version is still required before publication.

Future qualification also needs a separately reviewed collector. The current
native runner lacks the declaration-bound source configuration and preregistered
negative-frame metadata. Turning off prediction must retain structural terminal
timings; startup/reset images outside attempts must remain diagnostic frames.
Only fresh sessions acquired after a successful candidate freeze and their own
declarations can supply heldout evidence. All original attempts and preregistered
selection units must remain in that evaluation's source closure.

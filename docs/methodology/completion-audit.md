## Bounded experiments needed next

These are proposed experiment boundaries and decision rules to preregister before dispatch. They are not executed results or a substitute for the remaining work.

1. **Qualify endpoint scoring and episode resets.** Freeze the native state profile, gameplay/paused/result banks and source hash. Independently label new paused and natural-result fields before applying the reader; include values and digit combinations absent from construction. Retain raw frames and unknowns. Exercise at least three consecutive natural resets and three intended time-limit resets, including a normally handled advertisement if it occurs. Report every attempted boundary and manual intervention; require no wrong accepted score and no unsafe UI action in the bounded acceptance set. This is an initial engineering gate, not a high-confidence rare-failure estimate. Any error creates a new version and new held-out test, rather than relabeling construction as validation.
2. **Establish actual baseline distributions.** Run random and always-gas with the same vehicle/map/upgrades, input cadence, capture, endpoint rules and fixed horizon; add a clearly labeled stabilizing heuristic only as a comparator. Start with ten episodes each and record all exclusions, including capture/control/UI failures. Freeze a horizon long enough to test the competence threshold, before seeing candidate results; use the same horizon for learned-policy evaluation. The local game exposes no public seed control, so learner RNG seeds must not be described as controlled game seeds. A user demonstration is not an agent baseline.
3. **Screen direct learning before its governed hour.** The [direct screen protocol](direct-screen-learning.md) proposes 34 parameters in two independent pedal heads over eight image features and their masks. A bounded ten-minute pilot should test whether it finishes eligible generations and beats its fixed initialization on fresh evaluation episodes. Optimization consumes only qualified episode endpoints. Invalid/short-budget episodes never become zero or previous-HUD-max scores; interrupted partial generations retain their time/data costs. A result after the entire fixed episode is required. If the pilot is too slow or score coverage differs materially by candidate, fix the measurement bottleneck before interpreting a learning curve. The pilot remains prior search cost.
4. **Measure a real governed hour.** Freeze configuration, score rules, data/observation versions, clean SHA, learner seed and all priors. Snapshot the exact currently available policy at requested 300/600/1200/1800/2700/3600 seconds, recording actual time; do not use a later generation's score to select an earlier checkpoint. Count collection, perception, reset/ad waits, optimization and in-session serialization. Evaluate frozen checkpoints separately under identical real conditions, ideally at least ten episodes each; report evaluation duration outside the training clock. Repeat promising methods across independent learning seeds. Pass the existing provisional gate only if median real distance is at least 500 m, at least three times random median, and at least eight of ten episodes reach 250 m. Publish all component results and uncertainty. Even this gate does not establish high-level human performance without a separately measured human/reference distribution.
5. **Compare a restricted transfer route.** Train and evaluate the declared body-feature student with the original surrogate teacher and its full prior-compute lineage. Before real dispatch verify identical feature ordering, masks, temporal semantics and sign conventions; a matching schema hash does not prove matching distributions. Compare the same frozen student in held-out surrogate and actual episodes. Compare against a direct-screen actor using matched additional real exposure and report total prior compute separately. If both fail, report failure and feature/dynamics mismatch; a nondeployable oracle PPO score cannot be the denominator of a claimed identical-policy transfer ratio. Nominal surrogate distance is uncalibrated, so any nominal score ratio must retain that qualification and be accompanied by survival/crash/action-behavior comparisons.
6. **Test generalization and adaptation after initial competence.** Reserve one available real map, one available vehicle and their combination before learning on them; do not purchase or invent access to content. Record upgrade/configuration differences. Measure zero-shot scores, then adaptation at actual 5/10/30/60 minutes on a declared adaptation split and reevaluate the original condition for forgetting. Reusing prior test conditions for paired retention is useful but no longer an untouched selection set. Compare context-free history with a learned dynamics context only when there is data to train it; count profile labeling, pretraining and prior target exposure. Ten-minute surrogate children can provide a narrow synthetic result, not the required real adaptation curve.

## Screen dynamics identification without invented world coordinates

An evidence-based alternative to full physics calibration is a predictive observation model fitted to actual game trajectories. It could determine whether recent actions/history help predict visible outcomes and whether a learned context improves direct control. It is **not yet implemented or measured**, and the existing position/pitch fitter must not be fed raw car screen x as camera-compensated position.

Use current body-axis sine/cosine, their valid finite-difference rate, body-relative terrain/clearance, masks and timed gas/brake history. Predict the next valid body-axis vector, clearance/terrain changes, visible-state survival and forward displayed-progress increments. Angle error is measured modulo pi; clearance uses body spans; terrain uses image-relative units; progress is displayed HUD metres. Exclude signed translational speed, mass, gravity, collision contacts and fuel until independently observed or identified. A progress plateau can mean reverse motion, no motion or less than one displayed metre and must remain censored/ambiguous, not zero velocity.

Start with the already recorded corrected probes and gas trajectories as **construction/exploration**. They have been viewed repeatedly and are not a fresh held-out test. Collect a bounded set of short randomized pulse trajectories spanning 00/10/01/11 and both transition orders, with neutral releases and known resets. Include level/downhill/airborne segments only when those regimes can be independently labeled from pixels. Reserve complete new episodes and preferably a later session before fitting. Split by episode/session, never shuffled adjacent frames. Predeclare a small manual coordinate/angle label set for pose/terrain error and a separate numeric label set for OCR, so model error is not confused with unmeasured sensor error.

Join actions by actual OS transition timestamps and capture acquisition intervals. A requested code recorded beside a frame is not necessarily the action visible in that frame. Fit or compare a small bounded response-delay grid using training data only; include exposure duration and actual delta time. Treat captures spanning ambiguous transitions, long gaps or invalid body estimates as excluded with explicit counts. The source API completion timestamp is not proof of a new display frame. Action acknowledgement evidence and uncertainty must accompany any causal interpretation.

The first fitting comparison can use persistence, action-independent autoregression, regularized action-conditioned autoregression with an explicit gas-times-brake interaction, and a small nonlinear model only if the simpler model leaves systematic error. Fit one-step predictions, then evaluate fixed two/three/five-step rollouts without replacing predicted states with true intermediate observations. Report error and availability by action, regime, episode and horizon, plus inference cost. A proposed screening gate is at least 20% lower held-out normalized error than persistence **and** a measurable improvement over action-independent history on at least four reserved episodes, without an important regime's errors worsening unnoticed. This is an engineering screen requiring preregistration, not an already chosen physical fidelity standard. Prediction alone does not prove a policy will improve.

If prediction improves, learn a compact context from recent observation/action history and compare its downstream real control with the same actor lacking context at matched data/time. If it does not, inspect observability, pose uncertainty, lag and out-of-regime rollouts before adding model capacity. Parameter estimates must be stored with source frame/action hashes, training/held-out episode IDs, coordinate units, delay assumptions, feature version, model hash and uncertainty. A screen model can explain an effective response in observed coordinates; it cannot establish recovered proprietary physical parameters.

Completion criterion 3 can be met by an alternative only after an empirical decision: for example, a matched-budget restricted transfer/calibration route versus direct real learning, with held-out real quality, total experience, setup/learning time, uncertainty and failure modes. Invalid camera compensation and a nondeployable teacher justify trying direct learning; alone they do not prove it is the better final strategy. A direct strategy that misses the competence gate still leaves the principal objective unmet even if it outperforms the tested transfer baseline.
